# AetherCore-AI
Autonomous Windows System Optimizer, Thermal Guard & SaaS Platform.
## Architecture
- `desktop-app/` : Electron + React + Tailwind CSS (3-Color Mesh UI)
- `ai-engine/`   : Python + ONNX Runtime + Win32 Hardware Abstraction Layer
- `cloud-backend/`: Node.js + Express + MongoDB Atlas (Auth, MFA, UPI ₹99/mo, 30-Day Soft Delete)
- `installer-build/`: Windows Installer & OTA Update Configuration
